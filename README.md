# LearnDevopswithUsman

A production-oriented DevOps learning platform built to demonstrate
modern application development, CI/CD, containers, Kubernetes and GitOps.

## Planned Technology Stack

- React
- Node.js
- PostgreSQL
- Docker
- GitHub Actions
- Docker Hub
- Kubernetes
- Argo CD
- Terraform
- AWS EKS

## Application Features

- User Registration
- User Login
- Course Explorer
- Course Details
- Course Enrollment
- My Learning
- Learning Progress

## DevOps Goals

- Containerized application
- Automated CI pipeline
- Docker image publishing
- Kubernetes deployment
- GitOps with Argo CD
- Infrastructure as Code with Terraform
- AWS EKS deployment
- Monitoring and security
